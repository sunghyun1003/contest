자동차CM 통합 마케팅 애널리틱스 README
========================================

본 파일은 사내 AI 바이브코딩 경진대회 제출작인
'자동차CM 통합 마케팅 애널리틱스'의 실행 방법, 사용 방식, 주요 기능, 주의사항을 정리한 안내 문서입니다.


1. 가장 중요한 안내
-------------------
1) 본 제출물에 삽입된 모든 수치, 배너, 키워드, 성과 데이터는 공모전 제출 및 기능 시연을 위한 데모데이터입니다.
   실제 회사 실적, 실제 광고비, 실제 고객/계약 데이터가 아닙니다.

2) 본 대시보드는 원래 사내 내부망 환경에서 HTML 파일을 직접 실행하는 폐쇄형 구조로 개발되었습니다.
   결과물 제출이 URL 형태로만 가능함에 따라, 시연 목적에 한해 GitHub Pages를 통해 임시 배포하였습니다.
   배포 URL: https://sunghyun1003.github.io/contest/

3) 여러 개의 HTML 파일이 포함되어 있으나, 통합 애널리틱스 구동을 위해서는 반드시 index.html(위 URL)에 접속해야 합니다.
   개별 대시보드 URL로 직접 접속할 수도 있지만, 제출작의 의도는 index.html을 통해 3개 대시보드를 통합 구동하는 방식입니다.

4) 아래 4개 파일이 같은 GitHub 레퍼지토리 루트에 있어야 정상 작동합니다.
   - index.html         → 통합 셸 (메인 접속 URL)
   - mkt_dashboard.html → 성과 분석 대시보드
   - bn_library.html    → 크리에이티브 라이브러리
   - keyword_dashboard.html → 키워드 데이터랩


2. 파일 구성
------------
- index.html
  통합 런처 역할을 하는 메인 파일입니다. 홈 화면과 상단 메뉴를 통해 3개 대시보드로 이동합니다.

- mkt_dashboard.html
  자동차보험 실적/매출/채널/예측/이상감지 분석 대시보드입니다.

- bn_library.html
  자동차CM 배너 소재를 등록, 조회, 비교, 분석하는 크리에이티브 라이브러리입니다.

- keyword_dashboard.html
  검색/키워드 광고의 노출, 클릭, 설계, 청약 흐름을 분석하는 키워드 데이터랩입니다.

- [설명자료] 통합 마케팅 애널리틱스.pptx
  제출작의 기획 의도와 화면 예시를 설명하는 발표용 자료입니다.


3. 접속 방법 (URL 배포 버전)
-----------------------------
1) 아래 URL을 Chrome 또는 Edge 브라우저에서 엽니다.
   https://sunghyun1003.github.io/contest/

2) 홈 화면에서 원하는 대시보드를 선택하거나, 상단 메뉴에서 대시보드를 전환합니다.

3) 각 대시보드 안에서 샘플 데이터 확인, 파일 업로드, 필터 변경, 차트 확인, 데이터 가져오기/내보내기 기능을 사용할 수 있습니다.

권장 브라우저: Chrome 또는 Microsoft Edge
접속 방식: URL 직접 입력 또는 링크 클릭
인터넷 연결: 필수 (GitHub Pages를 통해 호스팅됨)

[참고] 로컬 실행 방법 (내부망 환경)
본 제출작은 원래 내부망 환경에서 아래 방식으로 실행하도록 설계되었습니다.
- 모든 HTML 파일을 하나의 폴더에 다운로드합니다.
- index.html 파일을 더블클릭하여 Chrome 또는 Edge 브라우저에서 실행합니다.
- 인터넷 연결 없이도 주요 기능이 동작합니다.


4. 통합 화면(index.html) 사용 방식
---------------------------------
index.html은 3개 대시보드를 하나의 화면에서 전환할 수 있도록 구성된 통합 셸입니다.

주요 기능
- 홈: 3개 대시보드의 목적을 요약하고 원하는 모듈로 이동합니다.
- 성과 분석 대시보드: mkt_dashboard.html을 화면 안에 불러옵니다.
- 크리에이티브 라이브러리: bn_library.html을 화면 안에 불러옵니다.
- 키워드 데이터랩: keyword_dashboard.html을 화면 안에 불러옵니다.
- 다크/라이트 모드: 통합 화면과 각 대시보드의 테마를 전환합니다.

사용 팁
- 심사 또는 시연 시에는 index.html URL에 접속하면 됩니다.
- 개별 HTML URL로 직접 접속하면 통합 메뉴 없이 해당 대시보드만 단독 실행됩니다.
- 통합 실행을 위해 GitHub 레퍼지토리 내 3개 대시보드 파일의 위치와 파일명을 변경하지 않는 것이 좋습니다.


5. 성과 분석 대시보드 기능 설명
-------------------------------
목적
자동차CM의 신규/갱신 실적, 매출, 채널별 성과, 예상 마감, 이상 신호를 한 화면에서 분석하기 위한 대시보드입니다.

주요 사용 방식
- 엑셀 업로드: 실적 raw 데이터를 불러와 분석합니다.
- JSON 불러오기: 백업 또는 공유받은 데이터를 복원합니다.
- 붙여넣기: 간단한 데이터는 텍스트 붙여넣기로 입력할 수 있습니다.
- 채널 인덱스 업데이트: 채널 분류 체계가 변경될 경우 인덱스를 갱신합니다.
- 자동불러오기: 사전 지정된 자동 데이터 파일이 있는 경우 불러옵니다.

탭별 기능
- 요약
  특정 기준일의 합산매출, 신규건수, 갱신건수, 총가입건수, 신규매출, 갱신매출을 요약합니다.
  전일/전주/비교일 대비 증감 흐름을 빠르게 확인할 수 있습니다.

- 월별현황
  월별 매출과 건수 추이를 확인합니다.
  합산매출, 신규매출, 갱신매출, 신규/갱신 건수 등 주요 지표의 전월/전년 대비 흐름을 볼 수 있습니다.

- 일별현황
  일자별 실적을 분석합니다.
  영업일, 비영업일, 결제일 등 일자 특성을 고려해 일별 변동을 확인할 수 있습니다.

- 채널분석
  오가닉, BSA, 퍼포먼스, 제휴, 비교추천 등 채널별 매출과 건수 기여도를 확인합니다.
  대분류/중분류/세부 채널 단위로 실적을 비교할 수 있습니다.

- 예측
  당월 또는 향후 월의 예상 실적을 산출합니다.
  확정 실적, 잔여일 구성, 도래자 데이터, 가중 이동평균 등을 참고해 예상 마감과 신뢰도를 제공합니다.

- 이상감지
  최근 데이터에서 급격한 증감이 발생한 채널과 지표를 탐지합니다.
  신규건수, 갱신건수, 신규매출, 갱신매출 기준으로 이상 신호를 확인할 수 있습니다.


6. 크리에이티브 라이브러리 기능 설명
------------------------------------
목적
자동차CM 배너 소재를 누적 관리하고, 소재별 성과를 비교하여 고성과 소재의 공통 특징을 파악하기 위한 라이브러리입니다.

주요 사용 방식
- 배너별 이미지, 채널, 운영 상태, 노출, 클릭, CTR, CPA, CPS 등을 등록합니다.
- 배너 갤러리에서 소재를 검색/필터링합니다.
- CSV 가져오기/내보내기로 다른 PC 또는 팀원에게 데이터를 공유할 수 있습니다.
- 추가/수정/삭제한 데이터는 기본적으로 현재 브라우저의 localStorage에 저장됩니다.

탭별 기능
- 대시보드
  전체 배너 수, 누적 노출수, 평균 CTR, 평균 CPA, 평균 CPS 등 전체 요약 지표를 확인합니다.
  성과 TOP 5와 채널별 평균 성과를 통해 우수 소재를 빠르게 찾을 수 있습니다.

- 배너 갤러리
  등록된 배너 소재를 카드 형태로 확인합니다.
  배너명, 채널, 태그 검색과 채널/상태/등급 필터, 노출/CTR/CPA/CPS 기준 정렬을 지원합니다.

- 배너 비교
  2~4개 배너를 선택해 CTR, CPA, CPS, CPC, 광고비, 설계 수, 청약 수 등을 나란히 비교합니다.
  우수 지표에는 표시가 되어 소재 간 강약점을 쉽게 볼 수 있습니다.

- A/B 아카이브
  A/B 테스트 이력을 기록하고 비교합니다.
  테스트 유형, 채널, A안/B안, 결과를 관리하여 이후 소재 제작 시 참고할 수 있습니다.

- 소재 DNA 분석
  배너 소재의 태그와 성과를 함께 분석합니다.
  고성과 소재에 반복적으로 나타나는 메시지, 이미지, 형식 등의 특징을 파악하는 용도입니다.

- 배너 추가
  신규 배너 소재를 등록합니다.
  이미지, 소재명, 채널, 상태, 태그, 성과 수치를 입력할 수 있습니다.

- 데이터 가져오기
  CSV 파일에서 배너 성과 데이터를 일괄 가져옵니다.
  필수 컬럼 예시는 name, channel, status, impressions, clicks, ctr 등입니다.


7. 키워드 데이터랩 기능 설명
---------------------------
목적
검색/키워드 광고 데이터를 기반으로 노출 → 클릭 → 설계 → 청약까지의 흐름을 분석하고, 키워드별 효율을 파악하기 위한 대시보드입니다.

주요 사용 방식
- 검색/키워드 광고 성과 raw 엑셀(.xlsx)을 불러옵니다.
- 필수 컬럼은 기간, 노출, 클릭, 비용(+VAT), 설계, 청약입니다.
- 분석 차원은 캠페인, 매체구분, 디바이스, 키워드분류, 키워드 등입니다.
- 데이터는 브라우저 IndexedDB에 저장되며, 같은 브라우저에서 재접속 시 유지됩니다.
- 데이터 내장 HTML 추출 또는 JSON 내보내기를 통해 백업/공유할 수 있습니다.

탭별 기능
- 개요
  광고비, 노출수, 클릭수, 산출수, 가입수 등 핵심 지표를 요약합니다.
  월별 광고비와 가입 추이, 자동 요약 인사이트를 확인할 수 있습니다.

- 검색 트렌드
  광고 노출 지수를 기반으로 검색 관심도 변화를 확인합니다.
  브랜드/일반/경쟁사 키워드 유형별 트렌드와 광고비·가입 추이를 비교합니다.

- 광고 현황
  매체별 예산 배분, PC/모바일 비중, 매체별 성과를 확인합니다.
  캠페인별 성과 순위를 통해 효율이 좋은 광고 집행 영역을 찾을 수 있습니다.

- 키워드 맵
  키워드별 노출 규모와 유형을 시각적으로 보여줍니다.
  브랜드, 일반, 경쟁사 키워드를 구분해 상위 키워드의 영향도를 파악할 수 있습니다.

- 인사이트
  키워드 성격 비중, 광고 지면 순위, 핵심 발견사항을 요약합니다.
  운영자가 별도 가공 없이 보고용 인사이트를 빠르게 확인하는 용도입니다.


8. 데이터 관련 주의사항
-----------------------
1) 본 제출물의 데이터는 모두 데모데이터입니다.
   실제 실적 검증, 경영 보고, 외부 공유 자료로 사용하면 안 됩니다.

2) 브라우저 저장 방식에 유의해야 합니다.
   일부 대시보드는 localStorage 또는 IndexedDB를 사용합니다.
   따라서 브라우저를 변경하거나 캐시/사이트 데이터를 삭제하면 입력한 데이터가 사라질 수 있습니다.
   URL 접속 환경에서는 같은 브라우저로 재접속해야 저장 데이터가 유지됩니다.

3) 변경사항은 서버에 자동 저장되지 않습니다.
   다른 사람에게 동일한 상태를 전달하려면 CSV/JSON/데이터 내장 HTML 내보내기 기능을 사용해야 합니다.

4) GitHub Pages는 정적 파일 호스팅으로, 서버 사이드 기능이나 데이터베이스는 지원되지 않습니다.
   모든 데이터 처리는 브라우저 클라이언트 단에서 이루어집니다.

5) 파일명과 레퍼지토리 구조를 유지해야 합니다.
   index.html은 상대경로로 각 대시보드 파일을 불러오므로, 파일명이 바뀌거나 폴더가 분리되면 대시보드가 열리지 않을 수 있습니다.


9. 시연 추천 순서
-----------------
1) 브라우저에서 https://sunghyun1003.github.io/contest/ 접속
2) 홈 화면에서 3개 모듈 구성 확인
3) 성과 분석 대시보드에서 요약/월별/채널/예측/이상감지 확인
4) 크리에이티브 라이브러리에서 배너 갤러리, 배너 비교, 소재 DNA 분석 확인
5) 키워드 데이터랩에서 개요, 검색 트렌드, 키워드 맵, 인사이트 확인
6) 마지막으로 다크/라이트 모드 전환 및 구성 설명


10. 한 줄 요약
--------------
이 제출작은 자동차CM 마케팅의 실적, 배너 소재, 키워드 광고 데이터를 하나의 브라우저 기반 통합 분석 환경으로 묶어 반복 리포트 작업을 줄이고, 마케팅 의사결정 속도를 높이기 위한 데모형 AI 바이브코딩 결과물입니다.
원래 사내 내부망 로컬 구동 방식으로 개발되었으며, 결과물 제출을 위해 GitHub Pages를 통해 임시 배포하였습니다.
