# 검증셋 — 성과분석 대시보드 Raw 파이프라인 (합계 정합)

`mkt_dashboard.html` 의 Raw 업로드 → 자동 집계 → 채널분석 합계 정합을 **망분리(오프라인) 환경에서 바로 검증**하기 위한 샘플입니다. 인터넷 연결 불필요.

## 파일
| 파일 | 용도 |
|---|---|
| `channel_index_sample.xlsx` | 채널 인덱스 (AFCCD → 대/중/소분류). **일부 코드를 일부러 누락** |
| `raw_sample.xlsx` | Raw 원본 (A~N 14컬럼). 인덱스에 없는 AFCCD·공백 AFCCD·퍼아워·해지(음수) 포함 |

`channel_index_sample.xlsx` 에는 `PA09999`, `PA08888` 두 코드가 **일부러 빠져 있습니다.** Raw 에는 이 코드가 들어 있어 `미분류`로 집계됩니다 → 합계 정합 검증의 핵심.

## 테스트 절차
1. `mkt_dashboard.html` 을 Chrome/Edge 로 엽니다. (단독 실행으로 충분 — index.html 불필요)
   - `file://` 에서 IndexedDB 가 막히면, 폴더에서 `python -m http.server 8000` 후 `http://localhost:8000/mkt_dashboard.html` (오프라인 유지).
2. **🗂 채널 인덱스 업데이트** → `channel_index_sample.xlsx` 업로드. (“6개 코드 등록” 메시지)
3. **Raw 업로드(엑셀)** → `raw_sample.xlsx` 업로드.
   - 상태줄에 `⚠️ 미분류 코드 2개 / 30건 …` 가 떠야 정상.
4. **요약 탭**과 **채널분석 탭**의 합계를 비교합니다.

## 합/불 판정
- ✅ **수정 후**: `미분류` 행이 표시되고, 채널 합 = 요약(307 / 60 / 37,200,000), 비중 합 = 100%.
- ❌ **수정 전(전임자 버전)**: `미분류` 행이 빠져 채널 합이 신규 **287**(−20) / 갱신 **50**(−10) / 합산매출 **34,200,000**(−3,000,000) 으로 요약과 어긋남. 비중 합도 100% 미만.

> 결론: `미분류`(=인덱스 미등록 AFCCD)가 전체 합계엔 들어가는데 채널 분류엔 빠지던 누수를 표·차트에 명시 노출해 정합을 맞춘 것이 이번 수정의 핵심입니다. 근본 해결(신규 코드 자동 인식)은 `PA09999` 등을 인덱스에 추가하면 해당 채널로 정상 귀속됩니다.

## 검증 규칙 (코드 반영됨)
- 신규/갱신: `신규갱신` 컬럼(값 `신규`/`갱신`) 기준. 헤더명이 달라도 값 기반 자동 탐지.
- 퍼아워 상품: 건수 0(제외), 매출 포함.
- 취소·해지·해지환입·환급·추징: 음수 값 그대로 **순합산(net)**.
- AFCCD 공백: 오가닉 > 직접방문 > 다이렉트.
- AFCCD 미등록: `미분류`로 집계 + 표/차트/상태줄에 노출.
